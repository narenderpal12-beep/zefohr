3. DESIGN DIRECTION (must differ from all six benchmarks)

Create a new visual identity while keeping the existing layout skeleton for each page:

Style: modern, warm, confident. Avoid generic purple-gradient SaaS look. Choose a distinctive palette (one strong primary, one warm accent, soft neutrals, a dark-mode-ready surface scale). Define everything as design tokens (CSS variables / theme file): colors, radius, shadows, spacing, type scale, motion durations.
Typography: one expressive display face for headlines plus one highly readable UI face. Tight, intentional type scale. Large numerals for stats.
Layout language: generous whitespace, bento-grid feature cards, layered UI mockups, subtle grain or mesh backgrounds, large rounded containers, section dividers with a unique shape motif.
Motion: meaningful only. Scroll-reveal, number count-up, tab cross-fades, card hover lifts, sticky-scroll storytelling for the lifecycle section. Respect prefers-reduced-motion.
Illustration/visuals: build product UI mockups in code (HTML/CSS/SVG) rather than stock photos. Use consistent icon set. No competitor logos or screenshots. Use clearly labelled placeholder logos for "trusted by".
Accessibility: WCAG AA contrast, keyboard navigable menus and tabs, focus rings, alt text, semantic landmarks.
Responsive: mobile first. Mega-menu becomes an accordion drawer. Tabs become swipeable. Sticky bottom CTA on mobile.
Performance: lazy-load below the fold, optimized images, no layout shift.
