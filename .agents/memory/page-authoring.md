---
name: Page-wise website authoring
description: Standing requirements for editable pages, reusable sections and navigation.
---

Existing website pages must remain available. Admin Content should be organised by a page dropdown, showing the sections linked to that page and allowing multiple additional sections. Admins can create dynamic pages and select them inside navigation menus, including mega-menu submenus.

**Why:** The user requested page-wise editing and clarified that new dynamic pages belong “inside menus,” while existing pages remain.

**How to apply:** Keep existing routes and content compatible when extending the page builder. New pages and sections inherit the website’s selected theme. Clearly distinguish shared content changes from page-only changes.

The “Add a page to a menu” form must always show an optional description, regardless of the selected destination. Mega-menu links without descriptions must have vertically centered labels.

**Why:** The user repeatedly reported the description as missing when it was shown only after selecting a mega-menu group.

**How to apply:** Do not hide the description based on the destination; explain where it is displayed. Treat whitespace-only descriptions as blank.

Additional homepage designs are optional choices in Appearance, not replacements for existing designs. Their sections should be reusable on other pages.

**Why:** The user requested a creative third homepage inspired by an external reference while keeping the earlier two available.

**How to apply:** Preserve the selected public homepage when adding a design. Let admins preview and explicitly save their choice, and support shared or page-only content when reusing sections.

Page editing must offer section ordering, reset to defaults and an editable hero slider with multiple layout choices.

**Why:** The user requested up/down controls, default resets and a hero slider with two or three options.

**How to apply:** Confirm content-discarding resets. A page-only section reset must not reset shared website content; relink a shared block instead. Keep the current live page unchanged until its edited layout is saved.

The hero title, description and button colors should remain editable in the admin. Unset colors use bright, theme-aware text and the bright brand-gradient buttons.

**Why:** The user asked for hero text and button color controls with bright defaults.

**How to apply:** Keep the default colors legible in both light and dark modes. For a custom button fill, provide contrasting button text unless the admin explicitly chooses a text color.
