---
name: Marketing layout controls
description: Preserve current public layout defaults when adding admin-controlled columns.
---

When adding layout controls to marketing sections, keep the existing public arrangement as the default. For Services, that means two cards in the first row and three in the next; the Blog listing remains two columns. Admins can set a repeating row pattern using 2, 3, 4 or 6 columns.

**Why:** The user explicitly corrected a prior change that replaced existing layouts with a global two-or-four-column setting.

**How to apply:** Extend the admin controls without changing the established public layout unless the user asks for a redesign.
