---
name: Simple integration editing
description: User requirement for editing integration entries without catalogue fields
---
Integration entries should be simple: choose Text or Image, then show only the text box or image browser and preview. Do not add category, slug, description, verification, or other entry options.

**Why:** The user rejected the expanded integration form and explicitly requested “either text or image nothing else.”

**How to apply:** Preserve this minimal interface across shared homepage integrations and the Integrations page. Keep older stored metadata compatible without exposing extra fields.
